# Product

## Register

product

## Users

The primary user is an individual managing a fictional personal health record in a university course project. A clinician is a verified, invited recipient who may receive temporary, scoped access to selected records. The main workflow is reviewing health information, adding records and measurements, understanding trends, and controlling access.

## Product Purpose

The project demonstrates how a personal health record system can centralize health information, make trends understandable, and give the patient visible control over sharing and access history. Success means the core flows work end to end with persistent demo data and honest security boundaries, while remaining straightforward to present and explain in a course review.

## Brand Personality

Professional, calm, trustworthy. The interface should communicate careful handling of sensitive information without sounding clinical, alarming, or promotional.

## Anti-references

Avoid toy-like medical graphics, flashy “health-tech” effects, tiny dashboard typography, decorative security claims, and controls that appear to work but only show a success message. Do not present simulated behavior as production-grade security or medical advice.

## Design Principles

1. Show the source, status, and consequence of every important action.
2. Patient control must be visible and enforced, especially for permissions and sensitive records.
3. Prefer understandable rules and evidence over unexplained health scores or AI claims.
4. Keep the main course-demo journey clear while preserving realistic success, empty, validation, and failure states.
5. Use one consistent interaction vocabulary across records, trends, permissions, and audit history.

## Accessibility & Inclusion

The PPT requires an accessible, responsive, easy-to-use interface but does not name a formal conformance level. Use WCAG 2.2 AA as an internal design and testing reference for contrast, keyboard access, focus visibility, labels, and responsive reachability. Do not claim formal certification. Support reduced motion, readable base text, and complete mobile navigation.
